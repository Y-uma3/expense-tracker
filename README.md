# 簡易記帳系統 (Simple Expense Tracker)

使用 Python 撰寫的指令列記帳工具，可記錄日常收入與支出，並提供類別統計與結餘計算。

## 功能

- 新增收入／支出紀錄（金額、類別、備註、時間自動記錄）
- 查看所有歷史紀錄
- 計算總收入、總支出、結餘
- 依類別統計支出佔比
- 刪除指定紀錄
- 資料自動儲存為 JSON 檔案，下次開啟程式仍會保留

## 使用方式

```bash
python3 expense_tracker.py
```

執行後依照選單輸入數字即可操作：

```
========== 簡易記帳系統 ==========
1. 新增紀錄
2. 查看所有紀錄
3. 收支總覽與類別統計
4. 查看指定月份紀錄
5. 刪除紀錄
6. 離開
```

## 技術說明

- 語言：Python 3
- 資料儲存：JSON 檔案（`records.json`），不需安裝資料庫
- 主要使用到的程式概念：
  - 迴圈與選單控制（`while`、`if/else`）
  - 函式拆分（新增、顯示、統計、刪除各自獨立成函式）
  - 字典與串列操作
  - 檔案讀寫（`json` 模組）
  - 例外處理（輸入格式錯誤時不會當掉）
